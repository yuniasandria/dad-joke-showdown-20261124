## The joke

> I told the houseplant it was growing on me. It said good — it was really putting down roots here.

Why this one: a double idiom-flip ("growing on me" / "putting down roots") on a
concrete everyday object, original phrasing (no stock dad joke, no classic
setup), punchline at the end, reads naturally aloud across a dinner table.

## Program

`main.py` (pure Python stdlib, no third-party imports) writes the single joke
to `/output/entry.txt`. `OUTPUT_DIR` may override the output directory for
local testing; the default is `/output`.
